# Créditos — KFAI (Kit de Ferramentas de Agente de IA)

O **KFAI** é um kit de **curadoria e configuração**: reúne ferramentas gratuitas
e open-source de terceiros, prepara um roteiro de instalação, skills e
documentação. **As ferramentas em si pertencem aos seus respectivos criadores.**

Este projeto **não** é autor dos programas abaixo e **não** inclui nenhum dado
pessoal, chave, token ou API dos desenvolvedores do kit.

---

## Ferramentas incluídas (todas gratuitas / de código aberto)

| Ferramenta | O que faz | Desenvolvedor | Licença |
|---|---|---|---|
| **Ollama** | Roda modelos de IA localmente | Ollama | MIT |
| **9Router** | Roteia várias IAs gratuitas (nuvem), com fallback automático | decolua | MIT |
| **Opencode** | Agente de IA no terminal (CLI) | Anthropic / comunidade | MIT / Apache-2.0 |
| **AionUi** | Interface gráfica para os agentes de IA | AionUi | licensa própria do produto |

## Modelos de IA citados (exemplos, só IDs de modelo)

Apenas **nomes** de modelos comuns (ex.: `qwen2.5`, `llama3.2`, `gemini`,
`nemotron`). Modelos pertencem aos seus criadores (Qwen: Alibaba,
Llama/Meta, Gemini: Google, Nemotron: NVIDIA, etc.). Nenhum peso/arquivo de
modelo é redistribuído aqui; o instalador baixa o modelo escolhido diretamente
da fonte oficial no equipamento de cada pessoa.

## Autoria

- **Curadoria, documentação, skills, scripts e o combo de configuração**: de
  autoria do preparador do kit.
- Reunitedo e mantido como um projeto open-source para ajudar quem não tem
  condições de pagar modelos de IA pagos.

## Marcas e avisos

Os nomes e logos das ferramentas são marcas de suas respectivas empresas.
O KFAI não é afiliado, endossado ou patrocinado por nenhuma delas. Nenhum nome
de marca é usado como branding próprio do KFAI.

## Segurança

Nenhuma chave, API key, token, cookie ou dado pessoal de nenhum usuário é
incluído (nem do autor, nem dos que instalam). Toda credencial nasce como
placeholder `SUA_CHAVE_AQUI` para o próprio usuário preencher.
